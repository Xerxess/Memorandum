# 核心组件

<https://reactnative.dev/docs/components-and-apis>

- React Native 提供了一系列内置的核心组件， 您可以直接在应用中使用。
- 不必局限于 React Native 自带的组件和 API。React Native 拥有一个由数千名开发者组成的社区。

## Basic Components 基本组件

View
构建用户界面最基本的组件。

Text
用于显示文本的组件。

Image
用于显示图像的组件。

TextInput
用于通过键盘向应用程序中输入文本的组件。

Pressable
一个包装组件，可以检测其任何子组件上各种阶段的按键交互。

ScrollView
提供一个可容纳多个组件和视图的滚动容器。

StyleSheet
提供类似于 CSS 样式表的抽象层。

## User Interface 用户界面

Button
一个用于处理触摸事件的基本按钮组件，可以在任何平台上完美渲染。

Switch
渲染布尔输入。

## List Views 列表视图

FlatList
用于渲染高性能可滚动列表的组件。

SectionList
类似于 FlatList ，但适用于分段列表。

## Android-specific Android 专用

BackHandler
检测硬件按钮按下操作以实现返回导航。

DrawerLayoutAndroid
在 Android 上渲染 DrawerLayout 。

PermissionsAndroid
提供对 Android M 中引入的权限模型的访问权限。

ToastAndroid
创建 Android Toast 提示框。

## iOS-specific iOS 专用

ActionSheetIOS
用于显示 iOS 操作表或分享表的 API。

## Others 其他的

ActivityIndicator
显示圆形负载指示器。

Alert
启动一个带有指定标题和消息的警告对话框。

Animated
一个用于创建流畅、强大且易于构建和维护的动画的库。

Dimensions
提供获取设备尺寸的接口。

KeyboardAvoidingView
提供一个可自动移开以避开虚拟键盘的视图。

Linking
提供一个通用接口，用于与传入和传出的应用程序链接进行交互。

Modal
提供了一种在封闭视图上方呈现内容的简单方法。

PixelRatio
提供对设备像素密度的访问。

RefreshControl
该组件用于 ScrollView 中，以添加下拉刷新功能。

StatusBar
用于控制应用程序状态栏的组件。
