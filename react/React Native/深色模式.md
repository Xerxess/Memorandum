
# 深色模式

- RN 主要依赖 JS 端的 Appearance 模块来获取系统偏好。
- Hook 模式：使用官方提供的 useColorScheme() Hook，它会根据系统主题返回 'light' 或 'dark'
- 采用样式对象或 CSS-in-JS。

> useColorScheme

```ts
// 适用场景：函数组件内部。
// 优点：代码简洁，会自动触发组件重新渲染（Re-render），不需要手动写监听逻辑。
import { useColorScheme } from 'react-native';

const MyComponent = () => {
  const theme = useColorScheme(); // 返回 'light' 或 'dark'
  const isDarkMode = theme === 'dark';

  return (
    <View style={{ backgroundColor: isDarkMode ? '#000' : '#fff' }}>
      <Text style={{ color: isDarkMode ? '#fff' : '#000' }}>
        当前是 {theme} 模式
      </Text>
    </View>
  );
};
```

> Appearance

```ts
// 适用场景：类组件（Class Components）、Redux 的 Action/Reducer、全局变量定义、样式表外部逻辑。
// 优点：可以在任何地方调用，不局限于 React 组件生命周期。

import { useEffect, useState } from 'react';
import { Appearance } from 'react-native';

const MyComponent = () => {
  const [theme, setTheme] = useState(Appearance.getColorScheme());

  useEffect(() => {
    // 1. 订阅变化
    // 当用户在手机系统设置里切换主题时，你的 App 需要实时响应。Appearance 提供了事件监听机制。
    const subscription = Appearance.addChangeListener(({ colorScheme }) => {
      setTheme(colorScheme);
      console.log('主题已切换为:', colorScheme);
    });

    // 2. 组件卸载时记得移除监听，防止内存泄漏
    return () => subscription.remove();
  }, []);

  return (
    // 根据 theme 渲染 UI
  );
};
```

## 图片

- 图片资源： 对于需要区分主题的图片（如图标），可以根据 isDarkMode 切换图片源。
- SVG (矢量图) 使用 react-native-svg，配合主题变量动态修改 fill 颜色。s

```ts
const isDarkMode = useColorScheme() === 'dark';

<Image 
  source={isDarkMode ? require('./dark.png') : require('./light.png')} 
/>
```
