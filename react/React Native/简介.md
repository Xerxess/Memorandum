# 简介

## React Native 两种创建应用方式

### React Native CLI

- React Native CLI 是 React Native 官方提供的命令行工具，它直接操作 iOS 和 Android 的原生项目，提供了对原生代码的完全控制权。
- 使用 React Native CLI 创建的项目包含完整的 iOS（.xcworkspace）和 Android（Gradle 项目）原生代码目录，开发者可以直接使用 Xcode 和 Android Studio 进行原生开发、调试和配置。
- 这种方式适合有原生开发经验的团队，或者需要深度定制原生功能的项目。
- React Native CLI 可以使用任何 React Native 生态中的库，包括那些包含原生代码的库（如 react-native-maps、react-native-video、react-native-fbsdk 等）。
- 在 React Native CLI 项目中，iOS 配置主要通过 Info.plist 和 entitlements 文件，Android 配置主要通过 AndroidManifest.xml 和 build.gradle 文件。这些配置需要使用对应的原生工具（Xcode、Android Studio）编辑，或者直接编辑 XML/Gradle 文件。
- 适用场景
    - 团队中有 iOS 或 Android 原生开发经验者
    - 项目需要使用特定的第三方原生库（如地图 SDK、支付 SDK、生物识别等）
    - 对应用体积有严格控制要求
    - 需要深度定制原生界面或交互
    - 项目需要支持旧版 iOS 或 Android 系统
    - 需要完整的 New Architecture 支持

```cmd
npx @react-native-community/cli@latest init MyApp
```

### Expo CLI

- Expo 是构建在 React Native 之上的完整开发和部署平台，它提供了一套完整的工具、服务和工作流，使得 React Native 应用的开发、构建、测试和发布变得前所未有的简单。
- Expo 由 Facebook（Meta）和开源社区共同维护，是 React Native 官方推荐的首选开发方式。
- Expo 的托管工作流只支持纯 JavaScript 编写的库，但 Expo SDK 本身已经内置了大量常用功能。
- 
    - 纯 JavaScript/TypeScript 开发者
    - 快速原型验证和 MVP 开发
    - 小型到中型项目
    - 预算有限（减少原生开发投入）
    - 快速迭代、快速发布
    - 团队不需要原生开发经验
    - 使用 Expo SDK 已涵盖的功能即可满足需求

```cmd
npx create-expo-app@latest MyApp
```
