# 定时器

## NSTimer

NSTimer 是开发者最熟悉的传统方案，适合执行精度要求不是极高的重复性任务。

- 依赖 RunLoop
- 精度 中
- 优势 API 简单，适用性广
- 劣势 受 RunLoop 繁忙度影响，易产生循环引用
- 场景
  - 简单的延迟或低频重复任务，首选 Block 版本的 Timer。

```swift
// 1. 创建并自动运行（最简单）
let timer = Timer.scheduledTimer(withTimeInterval: 1.0, repeats: true) { [weak self] _ in
    guard let self = self else { return }
    print("定时任务执行中...")
}

// 2. 解决滚动视图 (ScrollView) 停止触发的问题
// 默认在 .default 模式，滑动列表时会停止。需手动加入 .common 模式
RunLoop.current.add(timer, forMode: .common)

// 3. 停止定时器
timer.invalidate()
```

## DispatchSourceTimer (GCD)

基于操作系统内核的定时器，不受 RunLoop 状态影响。

- 依赖 系统内核
- 精度 高
- 优势 不受 RunLoop 影响，性能强
- 劣势 代码相对冗长，需手动管理声明周期
- 场景
  - 涉及支付、抢购等对秒级精度有严格要求的场景，建议使用 GCD 定时器。
  - 验证码倒计时：不依赖定时器的触发次数，而是计算时间差

### TimeInterval、DispatchTime、DispatchWallTime

- TimeInterval (秒表)
  - 含义：描述的是一段相对时长（Duration）。
  - 特点：它不关心现在几点，只关心“经过了多久”。
- DispatchTime  (系统时钟 / 纳秒)
  - 含义：描述的是从手机开机那一刻起经过的纳秒数。
  - 它不会随着用户修改系统时间而改变，也不会因为系统自动同步时间而跳变。
  - 致命伤：手机休眠（Sleep）时，它会停止计数。 如果你设置 10 秒后执行，结果手机锁屏休眠了 1 minute，那么这个任务要在 1 minute 10 秒后才会执行。
- DispatchWallTime (挂钟 / 绝对时间)
  - 含义：描述的是北京时间、伦敦时间这种绝对的时间。
  - 特点：它会随着系统时间被修改而改变。 如果用户手动把手机时间往后调了 1 小时，原本设定的任务可能立刻就会触发。
  - 优点：手机休眠时它依然有效。 即使手机睡着了，闹钟到了绝对时间点也会尝试唤醒执行。

```swift
class TimerManager {
    private var timer: DispatchSourceTimer?

    func startGCDTimer() {
        // 1. 指定队列（主队列或后台队列）
        let queue = DispatchQueue.main 
        timer = DispatchSource.makeTimerSource(queue: queue)
        
        // 2. 设置时间（立即开始，每秒执行，容差为0）
        timer?.schedule(deadline: .now(), repeating: .seconds(1), leeway: .nanoseconds(0))
        
        // 3. 设置回调
        timer?.setEventHandler { [weak self] in
            print("GCD 定时器触发")
        }
        
        // 4. 启动（创建后默认是挂起状态）
        timer?.resume()
    }
    
    func stopTimer() {
        timer?.cancel()
        timer = nil
    }
}
```

## CADisplayLink

特殊的定时器，其频率与屏幕刷新率（通常是 60Hz 或 120Hz）完全同步。

- 依赖 屏幕刷新
- 精度 极高
- 优势 UI 刷新完全同步
- 劣势 仅限与刷新频率成倍数的关系
- 场景
  - 涉及高频、平滑的 UI 更新（如自定义动画），必须选 CADisplayLink

```swift
class AnimationView: UIView {
    private var displayLink: CADisplayLink?

    func startAnimation() {
        // 注意：这里 self 被强引用了
        displayLink = CADisplayLink(target: self, selector: #selector(updateUI))
        
        // 绑定到 RunLoop
        displayLink?.add(to: .main, forMode: .common)
    }

    @objc private func updateUI() {
        // 每一帧都会调用（通常每秒60次）
        print("屏幕刷新中...")
    }

    func stop() {
        displayLink?.invalidate()
        displayLink = nil
    }
}
```
