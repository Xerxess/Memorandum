## SwiftUI 将基于视图的目标堆叠在堆栈导航路径中基于值的目标之上

从概念上讲，SwiftUI 将基于视图的目的地堆叠在堆栈导航路径中基于值的目的地之上。例如，下面的代码将上面示例中的 RecipeDetailView 替换为 NavigationLink：

```swift

@Observable
class NavigationManager {
    var path: [Color] = [] {
        willSet {
            print("will set to \(newValue)")
        }
        didSet {
            print("didSet to \(path)")
        }
    }
    
    @discardableResult
    func navigateBack() -> Color? {
        path.popLast()
    }
}

    @State private var navigationManager = NavigationManager()

                    // NavigationLink.init(destination:label:) 位于 堆栈导航路径 之上

                    // 误表现为： root -> mint -> Push Recipe View -> pink -> Push Recipe View -> pink -> Push Recipe View

                    // 真实表现为： root -> mint -> Push Recipe View(点击Push another view后) -> Push Recipe View(点击Push another view后) -> Push Recipe View -> pink 

                    // 可以理解为 先 path [] 后 NavigationLink.init(destination:label:)
```
