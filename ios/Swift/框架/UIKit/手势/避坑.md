# 避坑

## Touch events

- 重点理解hitTest递归顺序,对于在父视图上统一处理事件时可以更清晰

### hitTest递归顺序

 ```swift
// 结构
// 同级视图递归时是从最顶部视图层开始，即从上到下，对于subviews是从最后一个视图到第一个视图
// rootview 统一处理事件，下面代码是重写的rootview hitTest
//    - subview1
//    - subview2
//    - subview3
//    - subview4
override open func hitTest(_ point: CGPoint, with event: UIEvent?) -> UIView? {
    let view = super.hitTest(point, with: event)
    print(view)
    return view
}

// 当点击subview4
// 输出：
// subview4

// 当点击subview3
// 输出：
// subview4
// subview3

// 当点击subview2
// 输出：
// subview4
// subview3
// subview2

// 当点击subview1
// 输出：
// subview4
// subview3
// subview2
// subview1
 ```


### 相同视图hitTest会多次执行

 ```swift
// 相同视图hitTest会多次执行，可采用以下方式每一轮点击探测中只会执行一次
private var lastEventTimestamp: TimeInterval = 0
override open func hitTest(_ point: CGPoint, with event: UIEvent?) -> UIView? {
    let view = super.hitTest(point, with: event)
    if let event = event, event.timestamp != lastEventTimestamp,self.point(inside: point, with: nil) {
        lastEventTimestamp = event.timestamp
        // 这里的代码在每一轮点击探测中只会执行一次
        print("点击探测逻辑触发（单次执行）")
    }
    return view
}
 ```

## 与Touch events

- 手势识别器优先级高于Touch events
- 都受hitTest影响

```swift
// 手势与Touch events无效
override func hitTest(
            _ point: CGPoint,
            with event: UIEvent?
        ) -> UIView? {
            return nil
        }
```
