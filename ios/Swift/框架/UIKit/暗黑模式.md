
# 暗黑模式

- 使用系统提供的语义化颜色
  - 背景色：view.backgroundColor = .systemBackground（浅色是纯白，深色是纯黑）。
  - 文本色：label.textColor = .label（浅色是黑，深色是白）。
  - 次要文本：.secondaryLabel。
  - 分割线：.separator。
- 定义自定义动态颜色 (Dynamic Colors)
  - 在 Assets.xcassets 中新建一个 Color Set
  - 代码创建逻辑颜色

```swift
let dynamicColor = UIColor { (traitCollection: UITraitCollection) -> UIColor in
    if traitCollection.userInterfaceStyle == .dark {
        return .black // 深色模式颜色
    } else {
        return .white // 浅色模式颜色
    }
}
view.backgroundColor = dynamicColor
```

## 监听和手动判断模式

```swift
// 在 UIViewController 或 UIView 中，你可以通过 traitCollection 获取当前模式。
let isDark = self.traitCollection.userInterfaceStyle == .dark
```

```swift
// 当用户切换系统主题时，系统会调用 traitCollectionDidChange。如果你手动绘制了图层（如 CALayer），需要在这里更新：
override func traitCollectionDidChange(_ previousTraitCollection: UITraitCollection?) {
    super.traitCollectionDidChange(previousTraitCollection)

    if self.traitCollection.hasDifferentColorAppearance(comparedTo: previousTraitCollection) {
        // 在这里更新 CALayer 的颜色（CGColor 不会自动变）
        myLayer.borderColor = UIColor.label.cgColor
    }
}
```

## 图片适配 (Symbol & Assets)

- SF Symbols：优先使用 SF Symbols，它们会自动适配颜色。
- 位图 Assets：在 Assets.xcassets 的图片属性里，同样将 Appearances 设为 Any, Dark，然后放入两张对应的图片即可。
