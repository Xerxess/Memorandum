
# 路由管理

## Coordinator 导航模式

Coordinator 模式的核心思想是将 “页面跳转逻辑” 从 ViewController 中抽离出来，交给一个专门的路由角色。


## Router 路由协议化（面向接口的跳转）

特点：极简，去掉了 Coordinator 的持有关系，直接由 VC 或 ViewModel 调用。
适用场景：中小型项目，不想写太多样板代码。

```swift
enum AppStep {
    case login
    case userProfile(userId: String, isEditable: Bool)
    case settings
    case webView(url: URL)
}

protocol RouterProtocol: AnyObject {
    func navigate(to step: AppStep, from vc: UIViewController?)
}

class AppRouter: RouterProtocol {
    // 单例或通过依赖注入传递
    static let shared = AppRouter()
    private init() {}

    func navigate(to step: AppStep, from vc: UIViewController?) {
        guard let navigationController = vc?.navigationController else {
            print("导航失败：未找到 NavigationController")
            return
        }

        switch step {
        case .login:
            let loginVC = LoginViewController()
            // 可以通过注入方式传递依赖
            navigationController.present(loginVC, animated: true)

        case .userProfile(let userId, let isEditable):
            let profileVC = ProfileViewController(userId: userId)
            profileVC.canEdit = isEditable
            navigationController.pushViewController(profileVC, animated: true)

        case .settings:
            navigationController.pushViewController(SettingsViewController(), animated: true)
            
        case .webView(let url):
            let webVC = WebViewController(url: url)
            navigationController.pushViewController(webVC, animated: true)
        }
    }
}

class HomeViewController: UIViewController {
    @objc func didTapProfileButton() {
        // 只需要告诉 Router 我要去哪里，传什么参数
        AppRouter.shared.navigate(to: .userProfile(userId: "123", isEditable: true), from: self)
    }
}
```

## URL-Based Router (组件化/解耦神器)

类似于 Web 的 URL 跳转（如 myapp://product/detail?id=123）。业界著名的库有 MGJRouter 或 URLRouter。

核心逻辑：每个模块在启动时向中央注册表注册自己的 URL。
优雅之处：彻底解耦。模块 A 甚至不需要 import 模块 B 的代码，只需要知道一个字符串 URL 就能跳转。
适用场景：大型 App、多团队协同、组件化架构。
