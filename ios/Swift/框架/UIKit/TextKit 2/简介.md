# TextKit 2

TextKit 2 是 Apple 为 iOS/macOS 推出的新一代文本处理框架，是对原有 TextKit 的全面重新设计。它构建在 Core Text 之上，提供了更强大的文本布局和编辑能力。

TextKit 1 | TextKit 2
-|-
NSTextStorage |NSTextContentStorage
NSLayoutManager| NSTextLayoutManager
行片段 (line fragment)| NSTextLayoutFragment
lineFragmentRect(forGlyphAt:)| NSTextLayoutFragment.layoutFragmentFrame

## 核心架构

NSTextContentStorage 文本内容存储，管理原始文本
|
NSTextLayoutManager 布局管理器，处理文本布局
|
NSTextContainer  文本容器，定义可用区域
|
NSTextLayoutFragment 布局片段，渲染的基本单元

## Text management 文本管理

- class NSTextContentStorage 用于管理视图文本内容并生成布局所需的文本元素的具体对象。
- class NSTextContentManager 定义用于管理文本文档内容的接口和默认实现的抽象类
- class NSAttributedString 用于管理一系列字符的数据、布局和样式信息的文本字符串，以支持渲染。
- class NSMutableAttributedString 可变字符串，其文本部分带有关联属性（例如视觉样式、超链接或辅助功能数据）。

## Formatting and attributes 格式和属性

- class NSParagraphStyle 存储段落文本的格式信息。这些格式信息包括行间距、文本行缩进、行高、制表位位置等等。
- class NSMutableParagraphStyle
- class NSTextTab 用于在段落中定义制表符（Tab）的位置和对齐方式。
- class NSTextList 专门用于处理列表样式的排版（例如项目符号列表、数字编号列表）。

## Content elements 内容元素

- class NSTextParagraph 一个表示单个段落的类，该段落的内容由一个带属性的字符串支持。
- class NSTextListElement 表示文本列表节点的类
- class NSTextElement 表示文本布局最小单元（例如段落或附件）的抽象基类
- protocol NSTextElementProvider 文本内容管理器及其具体子类遵循的协议，该协议定义了与文本文档的自定义内容类型进行交互的接口。

## Location and selection 位置和选择

- class NSTextRange 表示文档内容中两个位置之间连续范围的类。
- class NSTextSelection 表示与插入点对应的单个逻辑选择上下文的类
- class NSTextSelectionNavigation 用于公开从对文本选择执行的操作中获取结果的方法的接口。
- protocol NSTextLocation 您实现的接口，表示文档内容中的抽象位置。

## Layout 布局

- class NSTextLayoutManager 用于管理自定义文本显示的文本布局和呈现方式的主要类。
- class NSTextContainer 文本布局发生的区域。
- class NSTextLayoutFragment 表示布局片段的类，通常对应于渲染表面，例如图层或视图子类。
- class NSTextLineFragment 一个类，它将一行片段表示为文本布局片段内的单个文本布局和渲染单元。
- class NSTextViewportLayoutController 管理视口内的布局过程，并与其代理进行交互。
- protocol NSTextLayoutOrientationProvider 一组用于定义对象文本方向的方法。

## Attachments 附件

- class NSTextAttachment 属性字符串及其相关对象的附件特征值。
- class NSTextAttachmentViewProvider 将特定文档位置的文本附件与视图对象关联的容器对象。
- class NSAdaptiveImageGlyph 用于表示类似表情符号的图像的数据对象，该图像可以出现在带属性的文本中。
- protocol NSTextAttachmentContainer 一组方法，用于定义布局管理器中文本附件对象的接口。
- protocol NSTextAttachmentLayout 一组方法，用于定义从文本布局管理器到附件对象的接口。

## TextKit 1

- class NSTextStorage TextKit 的基本存储机制，用于存储系统管理的文本。
- class NSLayoutManager 用于协调文本字符布局和显示的对象。
