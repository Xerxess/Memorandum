# 小笔记

## UINavigationController、UINavigationBar、UINavigationItem、UIBarButtonItem 关系

- UINavigationController (管理者/容器)：它是大管家，负责管理整个导航堆栈（Stack）和页面的跳转逻辑。
  - 容器 (Controller)
  - 维护 viewControllers 栈，控制 Push/Pop 动作。
  - 包含 NavigationBar。
- UINavigationBar (表现层/外壳)：它是导航栏的视觉实体，属于控制器的属性。所有页面共用同一个 Bar，但显示的内容会随页面切换而刷新。
  - 视图 (View)
  - 导航栏那条横线及其背景，设置背景色、透明度等外观样式。
  - 属于 NavigationController。
- UINavigationItem (配置项/数据模型)：每个 UIViewController 都有自己的 navigationItem。它相当于一份“菜单”，告诉导航栏（NavigationBar）在当前页面应该显示什么标题、什么按钮。
  - 模型 (Model)
  - title, leftBarButtonItem, rightBarButtonItem。
  - 属于每个 UIViewController。
- UIBarButtonItem (具体组件/零件)：它是具体放在导航栏左侧或右侧的按钮
  - 组件 (Item)
  - 具体的按钮，可以是图片、文字或自定义 View。
  - 被 navigationItem 持有。

### 改样式

- 所有页面的背景颜色，应该找 navigationController.navigationBar
- 改当前页面的标题或右上角按钮，应该找 self.navigationItem

### iOS 13 中改样式

- UINavigationBarAppearance
- standardAppearance: 常规状态（用户滚动页面后）。
- scrollEdgeAppearance: 边界状态（页面顶部，内容未滚动时，通常用于透明或大标题效果）。
- compactAppearance: 紧凑状态（横屏等小尺寸导航栏）。

#### 全局修改（推荐在 AppDelegate 中设置）

```swift
if #available(iOS 13.0, *) {
    let appearance = UINavigationBarAppearance()
    
    // 设置为不透明背景并配置颜色
    appearance.configureWithOpaqueBackground()
    // appearance.configureWithDefaultBackground()
    appearance.backgroundColor = .systemBlue
    
    // 配置标题颜色
    appearance.titleTextAttributes = [.foregroundColor: UIColor.white]
    
    // 去除分割线并应用样式
    appearance.shadowColor = .clear
    
    // standardAppearance: 标准样式，scrollEdgeAppearance: 滚动边缘样式
    navigationController?.navigationBar.standardAppearance = appearance
    navigationController?.navigationBar.scrollEdgeAppearance = appearance
}
```

## 禁用原生导航长按展示堆栈列表

- 没有相关配置，可采用leftBarButtonItem自定义返回
- 导致系统滑动返回失效，需要处理

```swift
private func setupCustomBackButton() {
    // 1. 判断是否不是根视图（根视图不需要返回按钮）
    guard let navigationController = self.navigationController,
            navigationController.viewControllers.count > 1 else { return }
    
    // 2. 创建自定义返回按钮（替换为你想要的图标）
    let backImage = UIImage(systemName: "chevron.left.circle") // 你的自定义图标
    let backItem = UIBarButtonItem(image: backImage,
                                    style: .plain,
                                    target: self,
                                    action: #selector(backAction))
    
    // 3. 设置为左侧按钮
    self.navigationItem.leftBarButtonItem = backItem
    let appearance = UINavigationBarAppearance()
    // 核心：配置为默认背景（这会自动开启系统的毛玻璃材质）
    appearance.configureWithDefaultBackground()
    
    // 如果想要微调毛玻璃后的“底色”（比如带一点白色的毛玻璃）
    appearance.backgroundColor = UIColor.secondarySystemBackground.withAlphaComponent(0.5)
    
    // 仅应用到当前页面的 navigationItem
    navigationItem.standardAppearance = appearance
    navigationItem.scrollEdgeAppearance = appearance
}
```
