
# 场景示例

## Just

```swift
// 场景：已经有数据了，但函数签名要求返回 Publisher
let just = Just("这是现成的数据")
    .sink { print("Just 收到: \($0)") }
```

## Future (单次异步封装)

```swift
// 场景：把现有的闭包 API 包装成 Combine
func fetchSomething() -> Future<String, Never> {
    return Future { promise in
        DispatchQueue.global().asyncAfter(deadline: .now() + 1) {
            promise(.success("异步数据回来了"))
        }
    }
}
```

## Deferred (懒加载/解决 Future 立即执行问题)

```swift
// 场景：只有在有人订阅时，才执行内部代码（比如重新发起网络请求）
let deferred = Deferred {
    print("现在才开始创建内部的 Publisher")
    return Just(Int.random(in: 1...100))
}
```

## Empty (只发结束信号)

```swift
// 场景：某些条件下不想发任何值，直接结束
let empty = Empty<String, Never>()
    .sink(receiveCompletion: { _ in print("Empty 结束了") }, 
          receiveValue: { print("永远不会打印这个: \($0)") })
```

## Fail (只发错误)

```swift
// 场景：验证失败，直接抛错
let fail = Fail<String, URLError>(error: URLError(.badURL))
    .sink(receiveCompletion: { print("Fail 收到错误: \($0)") }, 
          receiveValue: { _ in })
```

## CurrentValueSubject (状态存储)

```swift
// 场景：用户设置、开关状态（有初始值，新订阅者能拿到当前值）
let theme = CurrentValueSubject<String, Never>("亮色模式")
print("当前值: \(theme.value)") // 0. 直接访问
theme.send("深色模式") // 1. 更新并广播
```

## PassthroughSubject (事件传递)

```swift
// 场景：点击事件、消息通知（没存货，只管订阅后发生的动作）
let buttonClick = PassthroughSubject<Void, Never>()
buttonClick.send() // 触发一次点击事件
```
