# 标记块节点

- struct BlockDirective 一个带有 text 属性的元素，可以包裹其他块级元素。
- struct BlockQuote 引用块
- struct CustomBlock
- struct ListItem
- struct OrderedList
- struct UnorderedList
- struct Paragraph
- struct Heading
- struct HTMLBlock
- struct ThematicBreak
- struct CodeBlock
- struct Table

Swift 类型 | Markdown 语法| 说明
-|-|-
BlockDirective|@Metadata { ... }|苹果扩展语法。用于 DocC 文档，普通的 GFM Markdown 不常用。
BlockQuote|> 这是一个引用|侧边通常有竖线修饰的引用块。
CustomBlock|无固定语法|供解析器扩展使用的占位符，用于处理非标准插件。
ListItem|- [这里是节点内容]|列表中的单行，它是列表容器的直接子节点。
OrderedList|1. 第一步|有序列表，包含 startIndex（起始数字）。
UnorderedList|- 项目 1 或 * 项目 2|无序列表。
Paragraph | 这是一段普通文字。| 最常见的文本段落。
Heading | # 标题 1 或 ### 标题 3 | level 属性对应 # 的数量。
HTMLBlock |\<div\>Hello\</div\> | 原始 HTML 代码段，通常用于嵌入视频或特定样式。
ThematicBreak | --- 或 *** |水平分割线。
CodeBlock |\`\`\`swift code \`\`\`|带有 language 标签的长代码块。
Table|-|包含 Head 和 Body 的完整表格数据。
