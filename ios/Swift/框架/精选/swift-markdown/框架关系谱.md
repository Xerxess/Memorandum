# 框架关系谱

## Essentials

- protocol Markup 一个标记元素。
- struct MarkupChildren 由元素的子元素组成的惰性序列。
- typealias ChildIndexPath = [Int] 用于深入标记树的索引数组。
- struct TypedChildIndexPath 按索引和可选期望类型描述穿越标记树。
- struct DirectiveArgument 指令参数，从形式名称解析 value or name: "value".
- struct DirectiveArgumentText 提供给指令的参数文本，可以解析为各种类型的参数。
- Dstruct Document 代表整个文档顶层的标记元素。
- protocol LiteralMarkup : Markup 仅用一些纯文本表示的元素。
- protocol PlainTextConvertibleMarkup : Markup 一个无需格式化即可转换为纯文本的元素。

## Visit Markup 访问标记

- protocol MarkupVisitor 访问标记元素并返回结果。与 Walker 类似，但它不会自动向下遍历子节点
- protocol MarkupWalker 用于遍历标记树而不改变它的接口。 自动递归访问每一个节点及其子节点。
- protocol MarkupRewriter 能够重写树中元素的 MarkupVisitor。专门用来修改文档结构的

## Formatter and Options

- struct MarkupFormatter 打印带有格式选项的标记树。
- struct MarkupDumpOptions 打印标记树的调试描述时的选项。
