# 结构体

```rust
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64,
}

fn main() {
    let user1 = User {
        active: true,

    };

## 使用没有命名字段的元组结构体来创建不同的类型

fn main() {

```

## 方法语法

- 方法（method）与函数类似：它们使用 fn 关键字和名称声明，可以拥有参数和返回值，同时包含在某处调用该方法时会执行的代码。不过方法与函数是不同的，因为它们在结构体的上下文中被定义（或者是枚举或 trait 对象的上下文，将分别在第六章和第十八章讲解），并且它们第一个参数总是 self，它代表调用该方法的结构体实例。

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn area2(self:&self) -> u32 {
        self.width * self.height
    }
}
```

### 关联函数

- 关联函数 (Associated Functions) 指的是在 impl 块中定义，但第一个参数不是 self 的函数。
- 最直观的理解就是：它相当于 PHP 的静态方法 (Static Method) 或 Go 中不接收 receiver 的常规函数。

```rust
struct Player {
    id: u32,
    hp: i32,
}

impl Player {
    // 这是一个【关联函数】，因为它没有 self 参数
    // 习惯上常用于构造函数
    fn new(id: u32) -> Self {
        Self {
            id,
            hp: 100,
        }
    }

    // 这是一个【方法】，因为它有 &self
    fn take_damage(&mut self, amount: i32) {
        self.hp -= amount;
    }
}

fn main() {
    // 调用关联函数：使用 ::
    let mut hero = Player::new(1); 
    
    // 调用方法：使用 .
    hero.take_damage(20); 
}
```

### 多个 impl 块

```rust
impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

impl Rectangle {
    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}
```
