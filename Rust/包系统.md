
# 包系统

- Cargo 是 Rust 的构建系统和包管理器
- 编写复杂的 Rust 程序时，你将添加依赖项，如果使用 Cargo 启动项目，则添加依赖项将更加容易。
- Cargo.toml  文件使用 TOML (Tom’s Obvious, Minimal Language) 格式

## 安装 Cargo

```cmd
# 检查是否安装了 Cargo
cargo --version
```

## Cargo 创建项目

```cmd
# 创建项目
cargo new hello_cargo

#  构建了项目
cargo build

# 发布（release）构建
cargo build --release

# 直接运行了二进制文件
cargo run

# 快速检查代码确保其可以编译，但并不产生可执行文件
cargo check
```
