
# 数据类型

## 标量类型

### 整型

长度| 有符号| 无符号
-|-|-
8-bit| i8| u8
16-bit| i16| u16
32-bit|i32| u32
64-bit| i64| u64
128-bit| i128| u128
架构相关| isize| usize

### 整型字面值

数字字面值 |例子
-|-
Decimal (十进制) |98_222
Hex (十六进制)| 0xff
Octal (八进制)| 0o77
Binary (二进制)| 0b1111_0000

### 浮点型

- Rust 的浮点数类型是 f32 和 f64
- 默认类型是 f64
- 所有的浮点型都是有符号的

```rust
let x = 2.0; // f64

let y: f32 = 3.0; // f32
```

### 布尔类型

```rust
let t = true;

let f: bool = false; // with explicit type annotation
```

### 字符类型

```rust
let c = 'z';
let z: char = 'ℤ'; // with explicit type annotation
let heart_eyed_cat = '😻';
```

## 复合类型

### 元组类型

- 元组是一个将多个不同类型的值组合进一个复合类型的主要方式。元组长度固定：一旦声明，其长度不会增大或缩小。

```rust
let tup: (i32, f64, u8) = (500, 6.4, 1);
```

### 数组类型

```rust
let a = [1, 2, 3, 4, 5];
let a: [i32; 5] = [1, 2, 3, 4, 5];
let a = [3; 5]; // 创建一个每个元素都为相同值 3 的数组
```
