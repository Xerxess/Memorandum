# 常量和变量

## 常量

- 不允许对常量使用 mut
- 声明常量使用 const 关键字
- 必须 注明值的类型

```rust
const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
```

## 变量

```rust
let x = 5; // 不可变
let mut x = 5; // 可变
```

### 遮蔽

```rust
fn main() {
    let x = 5;
    let x = x + 1;
    {
        let x = x * 2;
        println!("The value of x in the inner scope is: {x}");
    }
    println!("The value of x is: {x}");
}
```
