# 枚举

- 枚举也可以有方法 (impl)

```rust
enum WebEvent {
    PageLoad,                 // 单元变体
    KeyPress(char),           // 元组变体：携带一个字符
    Paste(String),            // 元组变体：携带一个字符串
    Click { x: i64, y: i64 }, // 结构体变体：携带命名字段
    ChangeColor(i32, i32, i32),
}

impl WebEvent {
    fn inspect(&self) {
        match self {
            WebEvent::PageLoad => println!("页面加载"),
            WebEvent::KeyPress(c) => println!("按下了: {}", c),
            _ => println!("其他事件"),
        }
    }
}
```

## 内置枚举

### Option<T>

- 用于替代其他语言中的 null
- 标准库定义
- Option 类型应用广泛因为它编码了一个非常普遍的场景，即一个值要么有值要么没值。
- 替代 null
- 成员是 Some(T) 和 None
  - Some(T): 包含一个类型为 T 的值。
  - None: 表示没有值（类似于其他语言的 null）。
- 核心用法：
  - 取值：使用 .unwrap()（简单粗暴，失败则崩溃）或 .unwrap_or(default)（提供默认值）。
  - 链式处理：.map(|x| x + 1) 仅在有值时执行逻辑。
  - 安全获取：使用 if let Some(value) = opt { ... } 模式匹配。

```rust
enum Option<T> {
    Some(T),
    None,
}
```

```rust
let some_number = Some(5);
let some_char = Some('e');

let absent_number: Option<i32> = None;
```

### Result<T, E>

- 用于函数可能返回错误的情况
- 替代异常处理。
- 有两个变体
  - Ok(T)：操作成功，包含结果。
  - Err(E)：操作失败，包含错误原因。
- 核心用法
  - 问号操作符 ?：Rust 的核心语法糖。如果结果是 Err，直接从当前函数返回错误；如果是 Ok，则解构出值。
  - 转换：使用 .map_err(|e| ... ) 修改错误类型。
  - 互转：调用 .ok() 可以将 Result 丢弃错误信息并转为 Option。

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

```rust
let s = "123";
// parse 返回 Result<i32, ParseIntError>
// .ok() 将其转为 Option<i32>
if let Some(n) = s.parse::<i32>().ok() {
    println!("转换成功: {}", n);
}
```

```rust
// 问号操作符 ?
fn read_file_content() -> Result<String, std::io::Error> {
    let mut s = String::new();
    // 如果 open 失败，直接返回 Err；成功则继续
    let mut f = std::fs::File::open("hello.txt")?; 
    // 如果 read_to_string 失败，直接返回 Err
    f.read_to_string(&mut s)?; 
    Ok(s)
}
```

## match 表达式

- match 为强大的控制流运算符，它允许我们将一个值与一系列的模式相比较，并根据相匹配的模式执行相应代码。
- match (模式匹配) 是处理 Option 和 Result 的终极武器。
- 比 PHP 的 switch 或 Go 的 switch 强大得多，因为它是强制穷举且具有解构能力的。
- 在 Rust 中，如果你没有处理枚举的所有可能情况，代码无法编译。

```rust
enum Message {
    Quit,
    Move { x: i32, y: i32 }, // 结构体变体
    Write(String),           // 元组变体
}

let msg = Message::Move { x: 10, y: 20 };

match msg {
    Message::Quit => println!("退出"),
    Message::Move { x, y } => println!("移动到 x:{}, y:{}", x, y), // 直接拿到内部变量
    Message::Write(text) => println!("写入: {}", text),
    _ => (),
}
```

### if let 和 let else 简洁控制流

- 语法糖
- let else 可以理解为swift 中 提前退出 (guard)

```rust
// match 写法
let config_max = Some(3u8);
    match config_max {
        Some(max) => println!("The maximum is configured to be {max}"),
        _ => (),
    }

// if let
let config_max = Some(3u8);
    if let Some(max) = config_max {
        println!("The maximum is configured to be {max}");
    }
```

```rust
// match
let mut count = 0;
match coin {
    Coin::Quarter(state) => println!("State quarter from {state:?}!"),
    _ => count += 1,
}

// if let 和 else 表达式
let mut count = 0;
if let Coin::Quarter(state) = coin {
    println!("State quarter from {state:?}!");
} else {
    count += 1;
}
```

```rust
// let else 可以理解为swift 中 提前退出 (guard)
fn describe_state_quarter(coin: Coin) -> Option<String> {
    let state = if let Coin::Quarter(state) = coin {
        state
    } else {
        return None;
    };

    if state.existed_in(1900) {
        Some(format!("{state:?} is pretty old, for America!"))
    } else {
        Some(format!("{state:?} is relatively new."))
    }
}
```
