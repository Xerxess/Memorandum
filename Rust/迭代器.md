# 迭代器

- Rust 中的迭代器（Iterator）是一个强大且灵活的工具，用于对集合（如数组、向量、链表等）进行逐步访问和操作。
- 在 Rust 中，迭代器通过实现 Iterator trait 来定义

```rust
pub trait Iterator {
    type Item;
   
    fn next(&mut self) -> Option<Self::Item>;
   
    // 其他默认实现的方法如 map, filter 等。
}
```

## 创建方式

- .iter()：借用迭代。产生元素的不可变引用 &T。
- .iter_mut()：可变借用迭代。产生元素的可变引用 &mut T。
- .into_iter()：消耗迭代。转移所有权，产生 T。

## 常用操作符

- map：对每个元素进行转换。
- filter：根据条件保留元素。
- enumerate：获取索引和值的组合 (index, value)。
- zip：将两个迭代器压缩在一起。

## 消耗操作

- collect：最常用！将迭代器转换回集合（如 Vec 或 HashMap）。
- sum / product：求和或求积。
- for_each：对每个元素执行闭包操作。
- find / any / all：查找或判断。
