
# 标准库

- 标准库是 Rust 提供的一套稳定、跨平台的核心工具集

## 核心模块组成

- std::collections：我们讨论过的所有集合类型（Map, Set, Sequence）。
- std::iter：迭代器及其相关的适配器和辅助工具。
- std::io：输入输出（读写文件、标准读写流）。
- std::fs：文件系统操作（创建、删除文件或目录）。
- std::net：网络通信（TCP, UDP）。
- std::sync：多线程并发原语（如 Mutex, Arc, RwLock, mpsc 通道）。
- std::thread：原生线程管理。
- std::primitive：基础原始类型（i32, f64, char, bool, slice, array 等）。

## 三层递进架构

- core (libcore)
- alloc (liballoc)
- std (libstd)
