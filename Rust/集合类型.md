# 集合类型

## Slice 类型

- 在 Rust 中，切片 (Slice) 并不是一种集合容器，而是一种引用，它允许你引用集合中一段连续的内存序列，而无需拷贝数据。
- 切片（slice）允许你引用集合中一段连续的元素序列，而不用引用整个集合。
- 借用数据
- slice 是一种引用，所以它不拥有所有权。

```rust
// 字符串 slice（string slice）是 String 中一部分值的引用
let s = String::from("hello world");

// hello 是一个部分 String 的引用，由一个额外的 [0..5] 部分指定
let hello = &s[0..5];
let world = &s[6..11];
```

### 使用 Range 语法 来创建切片

- [..]：整个序列。
- [start..end]：左闭右开区间。
- [start..=end]：全闭区间。

## 数组 (Array)

- 长度 固定
- 内存位置 栈 (Stack)
- 扩容 不支持
- 性能 极高（无额外开销）

```rust
// 显式列出元素
let arr: [i32; 3] = [1, 2, 3];

// 简便初始化：[值; 长度]
let buffer = [0u8; 1024]; // 创建一个长度为 1024，初始值全为 0 的字节数组

let a = [1, 2, 3, 4, 5];
// a 是一个长度为 5 的整型数组

let b = ["January", "February", "March"];
// b 是一个长度为 3 的字符串数组

let c: [i32; 5] = [1, 2, 3, 4, 5];
// c 是一个长度为 5 的 i32 数组

let d = [3; 5];
// 等同于 let d = [3, 3, 3, 3, 3];

let first = a[0];
let second = a[1];
// 数组访问

a[0] = 123; // 错误：数组 a 不可变
let mut a = [1, 2, 3];
a[0] = 4; // 正确
```

## 动态数组(Vector)

- 拥有者 当 Vec 离开作用域时，它负责清理和释放内存。
- 与 Slice 不同 Slice 只是对一段连续内存的引用
- Vec<T> (Vector) 是最常用的动态数组。

```rust
// 创建一个空的 Vector
let mut v: Vec<i32> = Vec::new();

// 使用宏快速创建（最常用，类似 Go 的 v := []int{1, 2, 3}）
let mut v = vec![1, 2, 3];

// 添加元素
v.push(4); 

// let does_not_exist = &v[100]; // 尝试访问 vector 末尾之外的元素时让程序直接崩溃的场景
// let does_not_exist = v.get(100); // 当 get 方法被传递了一个数组外的索引时，它不会 panic 而是返回 None
```

```rust
// 遍历 vector 中的元素
let v = vec![100, 32, 57];
for i in &v {
    println!("{i}");
}
```

### 使用枚举来储存多种类型

```rust
enum SpreadsheetCell {
        Int(i32),
        Float(f64),
        Text(String),
    }

let row = vec![
    SpreadsheetCell::Int(3),
    SpreadsheetCell::Text(String::from("blue")),
    SpreadsheetCell::Float(10.12),
];
```

## String

- 在 Rust 中，String 本质上也是一种特殊的集合，它是 UTF-8 编码的 char 序列，底层由 Vec<u8> 包装而成。
- Rust 不允许使用索引获取 String 字符

```rust

let mut s = String::new();

let s = String::from("initial contents");

// 更新字符串
let mut s = String::from("foo");
s.push_str("bar");

// 索引字符串
let s1 = String::from("hi");
let h = s1[0]; // 报错  Rust 不允许使用索引获取 String 字符

// 遍历字符串的方法
for c in "Зд".chars() {
    println!("{c}");
    // З
    // д
}

for b in "Зд".bytes() {
    println!("{b}");
    // 208
    // 151
    // 208
    // 180
}
```

## HashMap

- HashMap<K, V> 类型储存了一个键类型 K 对应一个值类型 V 的映射。

```rust
use std::collections::HashMap;
let mut scores = HashMap::new();

scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);

// 访问哈希 map 中的值
let team_name = String::from("Blue");
let score = scores.get(&team_name).copied().unwrap_or(0);

// 遍历
for (key, value) in &scores {
        println!("{key}: {value}");
    }
```
