# 泛型

- 使用泛型定义函数、结构体、枚举和方法
- Rust 类型名的命名规范是首字母大写驼峰式命名法（UpperCamelCase）
- T 作为 “type” 的缩写是大部分 Rust 程序员的首选。

## 结构体

```rust
struct Point<T> {
    x: T,
    y: T,
}

let int_point = Point { x: 5, y: 10 };       // T 被推导为 i32
let float_point = Point { x: 1.0, y: 4.0 };  // T 被推导为 f64
```

## 函数

```rust
fn print_item<T: std::fmt::Display>(item: T) {
    println!("{}", item);
}
```

## 枚举

```rust
enum Option<T> {
    Some(T),
    None,
}

enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

## 方法定义中的泛型

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

fn main() {
    let p = Point { x: 5, y: 10 };

    println!("p.x = {}", p.x());
}
```
