
# UI布局工作节点

## 立项

- UI 架构搭建
  - 是否采用UI框架
  - 布局系统
- UI 布局规范
  - 图标管理
  - 新工程：CSS Modules 或 CSS-in-JS
  - 老项目改造：BEM + 命名空间
  - 第三方插件/组件库：唯一性前缀（如 swiper-、element-）

## 组件开发

- 目录规范
- 文档规范
- 编码规范

## 业务UI开发

- css 优先采用变量调整主题
- 先通过可视化能力强的AI大模型定义UI的基本框架
  - 从上到下，从左到右
  - 布局优先采用Flex弹性布局
  - 忽略UI定制效果图以及相关方案，快速布局整个UI脚手架
  - css 命名规范且符合行业标准
  - 对于需要后面版本精细调整的填充区
- 精细构建UI
  - 字体
  - 图片
  - 图标
