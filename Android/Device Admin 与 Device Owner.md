# Device Admin 与 Device Owner

- 在 Android 企业级控管中，这是两个完全不同维度的权限级别：

| 权限级别                 | 激活方式                                                                             | 静默安装能力                                            | 卸载表现                                                         |
| ------------------------ | ------------------------------------------------------------------------------------ | ------------------------------------------------------- | ---------------------------------------------------------------- |
| Device Admin(设备管理器) | 通过你这段代码，在应用内弹窗，由用户手动点击“激活”。                                 | 没有静默安装特权。只能调用普通安装，且必然会弹窗。      | 可以被普通用户在系统设置里取消激活并卸载。                       |
| Device Owner(设备所有者) | 通过 ADB 命令行 dpm set-device-owner 激活（且激活前手机内不能有任何账号/必须纯净）。 | 拥有最高静默安装特权（STATUS_SUCCESS 级别的无感覆盖）。 | 受到系统级保护，卸载时会报 DELETE_FAILED_DEVICE_POLICY_MANAGER。 |
