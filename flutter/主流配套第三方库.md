# 主流配套第三方库

## 建议搭配

Dio + Riverpod + go_router + Freezed + ScreenUtil

## 官方推荐

- json_serializable:通过注解（Annotation）定义模型，由工具自动生成 .g.dart 序列化文件
- url_launcher: 用于在应用内或外部打开网页、拨打电话、发送邮件或短信。
- path_provider: 获取 Android 和 iOS 文件系统中的常用目录（如临时目录、文档目录）。
- shared_preferences: 简单的键值对存储，适用于保存配置项。
- camera: 提供对系统摄像头的完全控制，支持预览、拍照和视频录制。
- video_player: 基础的视频播放库，支持从资产或网络加载。
- google_fonts: 动态加载 Google Fonts 库中的数千种字体，无需手动打包字体文件。
- http: 官方出品的轻量级 HTTP 请求库，适合简单的网络交互。
- sqflite: Flutter 最主流的 SQLite 数据库插件，支持复杂的数据持久化需求。
- cached_network_image (Flutter Favorite): 加载网络图片并自动进行磁盘缓存，极大优化用户体验。

## 状态管理 (State Management)

- Provider：官方推荐，简单易上手，适合中小型项目。
- flutter_bloc：最流行、最严谨的方案，基于流（Stream），适合逻辑复杂、多人协作的大型项目。
- Riverpod：Provider 的进阶版，解决了 Provider 的 context 依赖问题，支持编译时安全，是目前社区最推崇的新一代方案。
- GetX：功能极多（状态管理、路由、依赖注入、工具类），上手极快，但争议也较多（侵入性强），适合快速原型开发。

## JSON 转模型

- json_serializable:通过注解（Annotation）定义模型，由工具自动生成 .g.dart 序列化文件
- Freezed: 目前社区最火的进阶库 在 json_serializable 的基础上增加了“不可变模型”（Immutable Models）支持，自动生成 copyWith、toString 等方法，极大提升开发体验。

## 网络

- dio HTTP 客户端（最流行）
- http 官方简单 HTTP

## 认证/安全

- flutter_secure_storage 安全存储
- crypto 加密解密

## 布局与 UI 组件 (UI & Layout)

- cached_network_image：网络图片加载首选。支持内存/磁盘缓存、占位图、错误图显示。
- flutter_screenutil：屏幕适配必备。让你可以按设计稿的尺寸（如 px）直接写代码，自动适配不同分辨率。
- flutter_easyloading / oktoast：全局的 Loading、Toast（黑色小弹窗）提示工具。
- pull_to_refresh：最强大的上拉加载、下拉刷新组件。
- lottie 
- flutter_spinkit 加载动画

## 数据持久化 (Storage)

- shared_preferences：保存配置信息（如是否登录、主题颜色）。
- hive：极其轻量且高性能的键值对数据库，纯 Dart 编写，速度比 SQLite 快得多，适合本地大批量数据缓存。
- sqflite：如果你需要标准的 SQL 数据库操作。

## 路由管理 (Routing)

- go_router：官方维护，目前最主流的声明式路由，支持 DeepLink，适合处理复杂的页面跳转逻辑。

## 工具类与功能增强 (Utilities)

- flutter_hooks 这是 React Hooks 的 Flutter 实现。它添加了一种新型的组件，并增强了代码复用性。
- device_info_plus：获取手机型号、系统版本等硬件信息。
- package_info_plus：获取 App 的版本号、包名。
- permission_handler：通用的权限申请库（相机、相册、定位等）。
- logger：美化控制台日志输出，支持不同级别（Info/Debug/Error）和颜色。
- event_bus：简单的跨页面事件通知（但建议优先通过状态管理实现）。
- image_picker 图片/相机选择
- connectivity_plus 网络状态
- uuid UUID 生成
- path 路径处理
- intl 日期/数字格式化

## 开发辅助 (Development Tooling)

- retrofit：配合 Dio 使用，像写 Java/Kotlin 一样通过注解写 API 接口。
- flutter_launcher_icons：一键配置 iOS/Android 的应用图标。
- native_splash：一键配置启动页（Splash Screen）。
