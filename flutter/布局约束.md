# 布局约束

- Flutter 布局与 HTML 布局（他们可能就是从 HTML 布局开始的）非常不同
- 布局步骤
  - 获取约束：widget 会从其父级获取自身的约束。约束只是一组由 4 个双精度浮点数组成的集合： 最小和最大宽度，以及最小和最大高度。
  - 遍历：widget 会遍历它自己的子组件列表。逐一告诉子组件的 限制条件
  - 定位：逐个定位其子组件 （沿 x 轴水平定位，沿 y 轴垂直定位）
  - 告​​知：组件会将自身的大小告​​知其父组件

# 布局限制

- 小部件只能在一定范围内决定自身的大小 它受到其父级设定的限制。 这意味着小部件通常 它不能随心所欲地增大尺寸 。
- 小部件的位置是由其父级决定的。
- 由于父级的大小和位置反过来又取决于它自己的父级，因此如果不考虑整个树，就不可能精确定义任何小部件的大小和位置。
- 如果孩子想要的尺寸与父母的不同， 父级没有足够的信息来进行对齐。 那么孩子的体型就可以被忽略了。 定义对齐方式时要具体明确。

# Tight constraints 严格约束

- 严格约束只允许一种可能性， 精确的尺寸。

# Loose constraints 宽松约束

- 宽松约束是指具有最小值的约束。

# Unbounded constraints 无界约束

- 盒子的约束是无界的 ，或者说是无限的
- 意味着最大宽度或最大高度被设置为 double.infinity 

# 注意点

- 屏幕是Container的parent时，它强制容器与屏幕大小完全相同
