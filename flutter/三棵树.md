
# 三棵树

- Widget 描述信息。
  - 不可变（Immutable）：一旦创建就不能修改。
  - 廉价且短命：每次 UI 变化，旧的 Widget 丢掉，新的 Widget 瞬间创建。它只是简单的配置信息，不占什么内存。
- Element 生命周期管理
  - 持有状态：比如 StatefulWidget 的 State 就是保存在对应的 StatefulElement 里的。
  - 复用控制：当 Widget 树更新时，Element 会对比新旧 Widget（通过 runtimeType 和 key）。如果没变，它只更新属性，不销毁重建，这保证了性能。
- RenderObject 实际渲染
  - 昂贵且长寿：创建它很费资源，所以 Element 会尽量复用它。
  - 负责细节：布局（Layout）、绘制（Paint）、命中测试（Hit Testing）。

## RenderObject

- 在 Flutter 的三棵树架构中，RenderObject 是负责“干实活”的核心角色。
- 直接决定了组件在屏幕上的位置、大小以及长什么样。
- 核心职责
  - 布局 (Layout)：计算组件的大小（Size）和位置。它是通过从父节点向子节点传递“约束（Constraints）”，子节点向父节点返回“尺寸（Size）”的机制来完成的。
  - 绘制 (Paint)：根据布局计算出的坐标和尺寸，调用底层的绘图 API（Canvas）将内容绘制到屏幕上。
  - 命中测试 (Hit Testing)：处理用户点击等交互事件，确定哪个 RenderObject 应该响应当前的点击。
- 由于直接继承 RenderObject 太底层，绝大多数情况下我们会继承它的子类 RenderBox（它处理了最常用的二维笛卡尔坐标系）。

```dart
import 'package:flutter/rendering.dart';
import 'package:flutter/material.dart';

// 第一步：创建 RenderBox 类
class RenderCustomColorBox extends RenderBox {
  Color _color;
  RenderCustomColorBox(this._color);

  // 当颜色改变时，通过 setter 通知重绘
  set color(Color value) {
    if (_color == value) return;
    _color = value;
    markNeedsPaint(); // 标记需要重新绘制
  }

  // 1. 布局阶段：决定大小
  @override
  void performLayout() {
    // 强制子组件撑满父组件给定的约束，或者给个默认大小
    size = constraints.constrain(Size(100, 100));
  }

  // 2. 绘制阶段：决定样子
  @override
  void paint(PaintingContext context, Offset offset) {
    final Paint paint = Paint()..color = _color;
    // 在画布上画一个矩形
    context.canvas.drawRect(offset & size, paint);
  }
}

// 第二步：创建 RenderObjectWidget
class CustomColorBox extends LeafRenderObjectWidget {
  final Color color;
  const CustomColorBox({super.key, required this.color});

  // 创建 RenderObject
  @override
  RenderCustomColorBox createRenderObject(BuildContext context) {
    return RenderCustomColorBox(color);
  }

  // 当 Widget 配置变化时（比如颜色变了），更新 RenderObject
  @override
  void updateRenderObject(BuildContext context, RenderCustomColorBox renderObject) {
    renderObject.color = color;
  }
}


// 第三步：使用你的自定义组件
Center(
  child: CustomColorBox(color: Colors.blue),
)
```
