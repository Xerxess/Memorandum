# 概念

在 Flutter 中，动画的本质是在短时间内快速改变 Widget 的属性（如大小、颜色、位置）并触发重绘。

## Flutter 的动画系统

### 隐式动画

- 最简单的方式。你只需要改变一个值，Flutter 会自动处理从旧值到新值的过渡。
- 常用组件：AnimatedContainer, AnimatedOpacity, AnimatedPositioned, AnimatedAlign。
- 特点：只需设置 duration（时长）和 curve（曲线），改变状态（setState）后，Flutter 会帮你算好中间帧。
- 适用场景：简单的缩放、淡入淡出或颜色切换。

```dart
import 'package:flutter/material.dart';

class ImplicitAnimationDemo extends StatefulWidget {
  @override
  _ImplicitAnimationDemoState createState() => _ImplicitAnimationDemoState();
}

class _ImplicitAnimationDemoState extends State<ImplicitAnimationDemo> {
  double _size = 100.0;
  Color _color = Colors.blue;

  void _animate() {
    setState(() {
      // 改变属性，动画会自动触发
      _size = _size == 100.0 ? 200.0 : 100.0;
      _color = _color == Colors.blue ? Colors.red : Colors.blue;
    });
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: _animate,
      child: AnimatedContainer(
        duration: Duration(seconds: 1), // 动画时长
        curve: Curves.easeInOut,        // 动画曲线
        width: _size,
        height: _size,
        color: _color,
        child: Center(child: Text('点我变大变色', style: TextStyle(color: Colors.white))),
      ),
    );
  }
}
```

### 显式动画

- 需要更精细的控制（如循环播放、停止、反向播放）时，需要使用显式动画。
- 核心组件
  - AnimationController：控制器的“开关”和“进度条”（0.0 到 1.0）。
  - Animation / Tween：定义值的范围（比如从 0 到 300，或从红色到蓝色）。
  - AnimatedBuilder / AnimatedWidget：负责根据动画值的变化重建 UI。
- 特点：需要管理生命周期（在 initState 创建，在 dispose 销毁）。
- 适用场景：Loading 旋转、复杂的组合动画、需要手动触发的交互。

```dart
import 'package:flutter/material.dart';

class ExplicitAnimationDemo extends StatefulWidget {
  @override
  _ExplicitAnimationDemoState createState() => _ExplicitAnimationDemoState();
}

// 必须混入 SingleTickerProviderStateMixin 以获取帧定时器
class _ExplicitAnimationDemoState extends State<ExplicitAnimationDemo> 
    with SingleTickerProviderStateMixin {
  
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    // 1. 初始化控制器
    _controller = AnimationController(
      duration: const Duration(seconds: 2),
      vsync: this, // 绑定当前 State
    )..repeat(); // 设置为无限循环播放
  }

  @override
  void dispose() {
    _controller.dispose(); // 2. 必须销毁控制器释放资源
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Center(
      child: RotationTransition(
        turns: _controller, // 3. 将控制器绑定到特定的 Transition 组件
        child: const FlutterLogo(size: 100),
      ),
    );
  }
}
```

### 低级/自定义动画

- CustomPainter：如果你觉得 Widget 限制了发挥，可以在 Canvas 上直接根据动画值画图（性能最高）。
- Rive / Lottie：导入设计师制作好的矢量动画文件，Flutter 只负责播放。
