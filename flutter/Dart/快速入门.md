# 快速入门(对比 JavaScript)

## 与javascript快速对照表

| JavaScript | Dart |
|------------|------|
| `const/let` | `final` / `var` |
| `undefined` | `null` |
| `array` | `List` |
| `object` | `Map` 或 `class` |
| `function` | `Function` |
| `===` | `==` (Dart 同一比较) |
| `null` | `null` (可空需 `?`) |
| `async/await` | `async/await` |
| `class` | `class` |
| `prototype` | 继承 / Mixin |
| `import` | `import` |

## 变量与类型

```dart
// Dart
String name = "Tom";
int age = 25;
double score = 98.5;

// 类型推断 (像 JS 一样)
var name = "Tom";      // String
var age = 25;          // int
var score = 98.5;      // double
```

## 基本类型

| JS | Dart | 说明 |
|----|------|------|
| `number` | `int` / `double` | 整数 / 浮点数 |
| `string` | `String` | 字符串 |
| `boolean` | `bool` | 布尔值 |
| `object` | `Map` | 字典 |
| `array` | `List` | 数组 |
| `undefined` | `null` | 空值 |

## 函数

```dart
// Dart
String greet(String name) {
  return 'Hello, $name';
}

// 箭头函数 (只能单表达式)
int add(int a, int b) => a + b;

// 可选参数
String greet(String name, [String? title]) {
  return title != null ? 'Hello, $title $name' : 'Hello, $name';
}

// 命名参数
String greet({required String name, String title = 'Mr.'}) {
  return 'Hello, $title $name';
}

// 调用
greet(name: 'Tom', title: 'Dr.');
```

## 空

```dart
// Dart (默认不可为空)
String name = 'Tom';     // ✅ 不能为 null
String? name = null;    // ✅ 加 ? 才能为 null

// 空断言 (确定不为 null)
String name = value!;

// 空合并
String displayName = name ?? 'Guest';

// 条件访问
user?.name;  // 如果 user 为 null，返回 null
```

## 类与对象

```dart
// Dart
class Person {
  final String name;    // 不可变
  int age;
  
  // 构造方法
  Person(this.name, this.age);
  
  // 命名构造
  Person.guest() : name = 'Guest', age = 0;
  
  // 方法
  String greet() => 'Hi, I\'m $name';
  
  // getter
  bool get isAdult => age >= 18;
}

var p = Person('Tom', 25);
var g = Person.guest();

// 继承
class Student extends Person {
  String grade;
  
  // 父类构造
  Student(String name, int age, this.grade) : super(name, age);
  
  @override
  String greet() => 'Hi, I\'m $name, grade $grade';
}
```

## 接口与 Mixin

```dart
// 接口 (隐式，所有类都实现接口)
class Animal {
  void speak() => print('...');
}

// 使用 implements
class Dog implements Animal {
  @override
  void speak() => print('Woof!');
}

// Mixin (代码复用)
mixin CanFly {
  void fly() => print('Flying!');
}

class Bird extends Animal with CanFly {}
```

## 控制流

```dart
// Dart (几乎一样)
if (score >= 90) {
  print('A');
} else if (score >= 60) {
  print('B');
} else {
  print('C');
}

// for 循环
for (int i = 0; i < 5; i++) {}

// for-in 遍历
for (var item in list) {}

// forEach (类似 JS)
list.forEach((item) => print(item));

// switch (更强大)
String grade = 'A';
switch (grade) {
  case 'A':
    print('Excellent');
    break;
  case 'B':
    print('Good');
    break;
  default:
    print('Unknown');
}
```

## 集合操作

```dart
// Dart (方法几乎相同)
var numbers = [1, 2, 3, 4, 5];

var doubled = numbers.map((n) => n * 2).toList();
var evens = numbers.where((n) => n % 2 == 0).toList();
var sum = numbers.reduce((a, b) => a + b);

// Dart 还有这种语法
var doubled = [for (var n in numbers) n * 2];
```

## 异步 (async/await)

```dart
// Dart (几乎一样!)
Future<void> fetchData() async {
  try {
    final response = await http.get(Uri.parse('https://api.example.com/data'));
    final data = jsonDecode(response.body);
    print(data);
  } catch (err) {
    print(err);
  }
}

// 返回值的 Future
Future<String> fetchName() async {
  await Future.delayed(Duration(seconds: 1));
  return 'Tom';
}
```
