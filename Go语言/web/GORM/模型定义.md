
# 模型定义

GORM 通过将 Go 结构体（Go structs） 映射到数据库表来简化数据库交互。

```go
type User struct {
  ID           uint           // 主键的标准字段
  Name         string         // 常规字符串字段
  Email        *string        // 指向字符串的指针，允许空值
  Age          uint8          // 无符号 8 位整数
  Birthday     *time.Time     // 指向 time.Time 的指针，可以为 null
  MemberNumber sql.NullString // 使用 sql.NullString 处理可为空字符串
  ActivatedAt  sql.NullTime   // 使用 sql.NullTime 作为可为空的时间字段
  CreatedAt    time.Time      // 由 GORM 自动管理创建时间
  UpdatedAt    time.Time      // 由 GORM 自动管理更新时间
  ignored      string         // 未导出的字段将被忽略
}
```

```go
package models
import (
    "time"
)
// User 模型 - 对应 users 表
type User struct {
    ID        uint      `gorm:"primaryKey"`      // 主键，默认使用名为 `id` 的字段
    Name      string    `gorm:"size:255"`        // varchar(255)，默认 255
    Email     string    `gorm:"unique"`          // 唯一索引
    Age       uint8     `gorm:"default:18"`      // 默认值
    Birthday  *time.Time                         // 可为 NULL
    CreatedAt time.Time `gorm:"autoCreateTime"` // 自动创建时间
    UpdatedAt time.Time `gorm:"autoUpdateTime"` // 自动更新时间
}
// 自定义表名
func (User) TableName() string {
    return "tbl_users" // 使用自定义表名而不是默认的 "users"
}
```

## 约定

- 主键：GORM 使用一个名为ID 的字段作为每个模型的默认主键。
- 表名：默认情况下 将结构体名称转换为 snake_case 并为表名加上复数形式 User->users 、GormUserName->gorm_user_names
- 列名:转换为 snake_case 作为数据库中的列名 Name -> name 、CreatedAt -> created_at
- 时间戳字段：GORM使用字段 CreatedAt 和 UpdatedAt 来自动跟踪记录的创建和更新时间。

// gorm.Model 的定义

## 字段标签

- 标签不区分大小写，但首选camelCase。
- 多个标签，它们应该用分号（;）分隔。
- 对解析器具有特殊含义的字符可以用反斜杠（\）转义，允许它们用作参数值。

```go
type UserWithTags struct {
    // 基础类型
    ID        uint      `gorm:"primaryKey"`                          // 主键
    Name      string    `gorm:"size:100;not null"`                   // 长度 100，非空
    Email     string    `gorm:"uniqueIndex;size:255"`                // 唯一索引
    Age       int       `gorm:"default:0"`                           // 默认值
    Salay     float64   `gorm:"precision:10;scale:2"`                // DECIMAL(10,2)
    IsActive  bool      `gorm:"default:true"`                        // 布尔值
    Birthday  *time.Time                                              // 可空时间
    CreatedAt time.Time `gorm:"autoCreateTime:milli"`                // 创建时间（毫秒级）
    UpdatedAt time.Time `gorm:"autoUpdateTime"`                      // 更新时间
    // 索引相关
    Status    string    `gorm:"index"`                               // 普通索引
    City      string    `gorm:"uniqueIndex:idx_city_status"`         // 组合唯一索引
    Status2   string    `gorm:"uniqueIndex:idx_city_status"`         // 组合唯一索引
    Priority  int       `gorm:"index:idx_priority"`                  // 普通索引
    Type      int       `gorm:"index:idx_priority"`                  // 组合索引
    // 列名自定义
    UserName  string    `gorm:"column:user_name"`                    // 自定义列名
    // 嵌入结构体
    Address   Address   `gorm:"embedded"`                            // 嵌套嵌入
    AddressID uint      `gorm:"-"`                                   // 忽略此字段
}
```
