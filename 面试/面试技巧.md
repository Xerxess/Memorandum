# 面试技巧

## 面对HR

- 核心：扬长避短，别给自已挖坑，突显优势，提高自身竞争力


```txt
个人信息亮点：如果高学历，985 务必讲述
专业：如果专业优势需要讲述
工作经历：不必讲述太多技术专业术语，讲一下自己的担任的职位，经验年限，最近一份工作的基本情况
项目经验：简单讲述一下在最近一份工作中的项目情况，数量，及最近一个项目的基本情况(在项目中自己的作用，如技术栈的选择等等)
其他的一些加分项：如有自己的git,分享过，参与过
反问阶段：公司的企业文化等与技术不相关的问题（如公司对员工有什么激励机制）
```

## 面对技术

- 侧重技术内容
- 多从做过的项目上介绍自己
- 当问到自己的不会技术时，尽量不要不回答


```txt
个人信息
工作经验
最好的项目
反问阶段：主要以技术相关（如公司目前的技术栈、公司现在有考虑引入什么新技术吗、现在AI这么火，公司有引入AI编程吗）
```

```txt
我叫XX,(学历高可加入)。
有xx年的开发工作经验，我对技术有深厚的兴趣，专业知识面宽。
精通(自己擅长的领域，不要给自己挖坑)等前端技术
熟悉XXX等前端，并拥有丰富的项目开发经验
准备一个最好的项目，根据这个项目讲述一下，根据项目的业务，和自己在这个项目中的角色。
最后，如何没有其他补充最好就停留在项目介绍上，引导面试官询通过项目询问问题

```
