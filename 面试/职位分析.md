
# 职位分析

## 初级

- 能做事

```
岗位职责：

1、负责公司产品网站、PC端/APP前端、小程序前端设计；
2、参与设计体验、流程的制定和规范，组织设计评3.独立承担Web前端开发任务；
4、利用Vue、react、nodejs, HTML、CSS.
JavaSeript、Jquery等各种Web技术进行产品的界面开发；
5、整体页面结构及样式层结构的设计、优化； 6、制作标准优化的代码，并增加交互动态功能； 7、进行丰富互联网的Web开发，致力于通过技术改善用户体验；
8、配合开发人员完成项目开发。

任职要求：

1、本科及以上学历，三年以上工作经验，精通（X） HTML、CSS、JS，至少精通一种JS框架，如vue/react/angular等；
2、具有探索精神，对新技术有浓厚的兴趣和一定的见解；
3、逻辑分析能力强，善于沟通且有较强的学习能力；
4、一年以上PC端设计工作经验和手机版网页工作经验
5、熟悉当前互联网的各种流行应用，在交互开发、用户体验等方面有自己的见解，能主动根据业务需要，提出合理的交互方案； 6、有使用ts、mpvue、uniapp、nodejs相关经验者优先。
```

## 中级

- 能解决问题

```
岗位职责：

1.承担Web前端相关的开发&优化任务； 
2. 前端架构搭建，编写通用组件，页面； 
3.前端框架与组件的规划、设计与开发实现； 
4. 解决各种技术难题，并通过吸收新技术； 
5. 追求并实现最优的用户体验及性能提升。

任职要求：

1.3-5年工作经验，本科学历，计算机相关专业，熟悉各种前端技术（包括HTML、CSS、JavaScript等），有HTML5/CSS3等Wleb 页面开发经验和案例；
2. 熟悉Reactjs/Vue 框架，掌握其原理；熟悉其他常用的JS框架，如 Angular 等；
3.熟练掌据es6/es7；
4. 具备跨终端（Mobile+PC），跨浏览器的前端开发能力，有丰富的关于Web标准、易用性、浏览器端原理以及网站性能优化等方面的知识；
5. 熟悉HTTP/SSL协议；
6. 熟悉前端工程化、模块化开发，有实践经验，可以熟练使用如gulp/webpack等，独立构建应用；
7. 有良好的的编码习惯，重视代码质量，善于利用工具； 8.解决各种技术难题，并通过吸收新技术保持技术的更新
```

## 高级

- 解决问题
- 能分享
- 要带动周边团队一起进步

```
岗位职责：

1.根据产品器求文档，进行产品设计；
2.通循公司编码规范并负责编码实现，参与产品前端性能优化、故障排查和解决，安全加固等工作； 3.与后端开发同学一起落地产品，并编写操作手册及安装部署手册等；
4.参与模块设计、承担系统和项目开发工作的同时， 能够指导初中级工程师，进行技术分享，共同促进团队成员进步；
5.研究分析业内主流技术实现，优化实现方案，不断改进产品功能。

任职要求：

1.本科及以上学历，计算机相关专业；
2. 拥有 5年以上前端工作经验，对解决多浏览器兼容性问题有丰富经验；
3. 深刻理解Web标准，对前端性能、可访问性、可维护性等相关知识有实际的了解和实践经验，有成功作品； 4. 理解并掌握Javascript语言核心技术DOM,BOM、AJAX、 Restful、JSON等，熟悉Javascript性能优化，精通Vue或React机架；
5. 有Node. js （express/koa）、npm、gulp、grunt、 webpack等使用经验，有前端工程化和模块化开发实践经验；
6.对各类系统界面设计及交互有浓厚的兴趣，具备良好的学习能力、洶通能力、分析及解决问題能力、优秀的团队协作精神，逻辑性强，个性乐观开朗。
```

## 专家

- 相对高级，更注重整体把控

```
岗位职责：

1、负责移动端H5前端项目的开发及性能优化；
2、负责微信小程序，快应用等产品通用架构设计和
开发；
3、负责前端技术选型和通用库开发并指导团队成员、
前端工程技术体系化建设；
4、培训和指导其他小伙伴；
5、推进前沿技术研究和新技术调哥。

任职要求：

1.5年及以上的web前端开发经验，有做过大型项目的研发和设计；
2. 需要扎实的前端基础（js、html、css），掌握前端框架VUE/react；
3.熟悉模块化、前端编译和构建工具，并深入理解其设计原理；
4. 掌握扎实的计算机知识（算法、数据结构），以及常用的网络协议；
5.熟悉与后台和底层的交互通信，熟悉混合开发的能力；
6. 有丰富的项目管理经验，有良好的洶通能力。
``
